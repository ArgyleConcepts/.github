# Argyle Concepts GitHub profile

The organization profile is published by placing `profile/README.md` in the default branch of the public `ArgyleConcepts/.github` repository.

## Contents

- `profile/README.md`: GitHub-compatible organization profile.
- `profile/assets/banner.png`: ready-to-use banner, rendered at 2× resolution.
- `profile/assets/banner.svg`: editable vector source.
- `profile/assets/logo.svg`: original logo from the Argyle website.

Use `main` as the repository's default branch; the banner link targets that branch. Upload the `profile` directory with its structure intact. The root README is setup documentation and does not appear on the organization page.

## Design and content

The banner adapts the website's diamond motif, dark background, teal/purple colors, serif/sans typography, and original headline. Service copy is based on the website source. Project descriptions are based on public repository contents; forks are explicitly identified. No private product or customer details are included.

GitHub strips custom CSS from profile READMEs. The profile therefore uses a static banner, native Markdown, supported HTML table layout, and ordinary links. Text remains native below the banner, and the banner has descriptive alternative text.

The website source was read from ArgyleConcepts/ArgyleConcepts-Web at commit 01df986a7ddae182ee60e5d29eb62ab075effe96. The deployed site's body text was unavailable through search, so parity with the deployed version could not be confirmed.
