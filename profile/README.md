## From our workbench

### [ArgyleMVU · Swift](https://github.com/ArgyleConcepts/ArgyleMVU-Swift)

A Swift package exploring the Model–View–Update approach: explicit state, messages, and commands. It brings an Elm-inspired structure to application code, with observable view models and asynchronous command execution.

**Swift · Application architecture · Model–View–Update**

### Open source we build on

Our public repositories also include forks of tools we use and explore. The original projects and their authors deserve the credit.

- **[FSharp.MinimalApi](https://github.com/ArgyleConcepts/FSharp.MinimalApi)** — our fork of [Lucas Teles's library](https://github.com/lucasteles/FSharp.MinimalApi) for defining ASP.NET Core Minimal APIs in F#.
- **[ESP32 SQLite](https://github.com/ArgyleConcepts/esp32-idf-sqlite3)** — our fork of the SQLite library for ESP32 with ESP-IDF.
